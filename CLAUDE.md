# anthony-sosa-insource

Static one-page site for Anthony Sosa / Insource. Everything deployable lives in `site/`;
there is no build step. See `README.md` for layout, local run and Cloudflare Pages settings.

- Edit `site/index.html` directly (CSS and the GSAP/Lenis animation script are inline).
- Do not upgrade the vendored libraries in `site/js/` unless asked.
